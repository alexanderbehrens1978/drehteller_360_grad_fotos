Benutzeranleitung

Diese Anleitung erklärt die Verwendung der 360° Drehteller Steuerungsanwendung. Sie führt Sie durch alle wichtigen Funktionen der Software, von der Projekterstellung bis zur Generierung von 360°-Ansichten.

1. Übersicht der Benutzeroberfläche

Die Anwendung besteht aus vier Hauptbereichen, die über die Navigationsleiste erreichbar sind:

  • Startseite: Überblick und Schnellzugriff auf Hauptfunktionen
  • Projekte: Verwaltung von Fotoprojekten
  • Einstellungen: Konfiguration der Hardware und Software
  • 360° Viewer: Anzeige der erstellten 360°-Ansichten
Tipp: Der aktuelle Status der Hardware (Arduino und Kamera) wird immer in der Statusleiste unten angezeigt.

2. Projektverwaltung

Die Projektverwaltung ist der zentrale Bereich für alle Ihre 360°-Fotoprojekte.

2.1 Neues Projekt erstellen

  1. Navigieren Sie zu Projekte in der Hauptnavigation
  2. Klicken Sie auf Neues Projekt
  3. Geben Sie einen Namen und optional eine Beschreibung ein
  4. Wählen Sie einen Winkelschritt (Standardwert: 15°)
  5. Klicken Sie auf Erstellen

Der Winkelschritt bestimmt, wie viele Fotos für eine vollständige 360°-Ansicht aufgenommen werden:

  • 5° = 72 Fotos
  • 10° = 36 Fotos
  • 15° = 24 Fotos
  • 30° = 12 Fotos
Tipp: Ein kleinerer Winkelschritt führt zu einer flüssigeren 360°-Ansicht, erhöht aber die Fotosession-Dauer und den Speicherbedarf.

2.2 Projekte verwalten

In der Projektübersicht können Sie:

  • Bestehende Projekte anzeigen und bearbeiten
  • Projekt-Details einsehen (Erstellungsdatum, Anzahl der Fotos)
  • Projekte löschen
  • 360°-Ansichten generieren
  • Fotosessions starten

3. Fotosession durchführen

3.1 Vorbereitungen

  1. Stellen Sie sicher, dass Arduino und Kamera korrekt angeschlossen und erkannt sind
  2. Platzieren Sie das Objekt mittig auf dem Drehteller
  3. Stellen Sie die Beleuchtung ein (gleichmäßige Ausleuchtung empfohlen)
  4. Richten Sie die Kamera auf das Objekt aus

3.2 Session starten

  1. Wählen Sie ein Projekt aus der Projektliste
  2. Klicken Sie auf Fotosession starten
  3. Überprüfen Sie die Kamera- und Drehteller-Einstellungen
  4. Klicken Sie auf Session starten

Die Session läuft nun automatisch ab:

1. Foto aufnehmen → 2. Drehteller rotieren → 3. Nächstes Foto aufnehmen → ... → N. Session abschließen
Tipp: Sie können eine laufende Session jederzeit mit dem Stop-Button abbrechen.

3.3 Manuelle Steuerung

Alternativ zur automatischen Session können Sie den Drehteller auch manuell steuern:

  1. Gehen Sie zur Startseite
  2. Nutzen Sie die Steuerelemente im Bereich "Manuelle Steuerung"
  3. Stellen Sie den Drehwinkel ein (5°-90°)
  4. Klicken Sie auf Drehen oder Foto + Drehen

4. 360°-Ansicht generieren

Nach Abschluss einer Fotosession können Sie eine interaktive 360°-Ansicht erstellen:

  1. Gehen Sie zur Projektübersicht
  2. Wählen Sie das gewünschte Projekt
  3. Klicken Sie auf 360° Viewer generieren
  4. Wählen Sie die gewünschte Session aus (falls mehrere vorhanden)
  5. Klicken Sie auf Generieren

Die Anwendung erstellt nun eine HTML-Datei mit der interaktiven 360°-Ansicht.

Tipp: Sie können die Qualität der generierten Ansicht im Bereich "Viewer-Einstellungen" anpassen (Bildgröße, Kompression).

5. 360°-Ansicht betrachten und teilen

Die generierten 360°-Ansichten können direkt in der Anwendung betrachtet werden:

  1. Gehen Sie zum Bereich 360° Viewer in der Hauptnavigation
  2. Wählen Sie das Projekt und die Session aus
  3. Die 360°-Ansicht wird geladen und kann interaktiv bedient werden

Bedienung des Viewers:

  • Ziehen Sie mit der Maus, um das Objekt zu drehen
  • Verwenden Sie das Scrollrad zum Zoomen
  • Nutzen Sie die Steuerelemente für Autorotation und Vollbild

5.1 Export und Teilen

Sie können die 360°-Ansicht exportieren und teilen:

  1. Klicken Sie im Viewer auf Exportieren
  2. Wählen Sie zwischen folgenden Optionen:
    • HTML-Paket: Komplette Viewer-Dateien zum Hochladen auf einen Webserver
    • Einzelbilder: Alle Fotos als ZIP-Archiv
    • GIF/Video: Animierte Darstellung der 360°-Ansicht
  3. Folgen Sie den Anweisungen zum Speichern oder Teilen

6. Einstellungen anpassen

Im Bereich Einstellungen können Sie die Anwendung konfigurieren:

6.1 Hardware-Einstellungen

  • Arduino: Port, Baudrate, Motorgeschwindigkeit
  • Kamera: Typ (Webcam/DSLR), Gerätepfad, Auflösung, Belichtungseinstellungen

6.2 Software-Einstellungen

  • Pfade: Speicherorte für Projekte und Fotos
  • Rotation: Standard-Winkelschritt, Drehrichtung
  • Viewer: Bildgröße, Kompression, Autorotation
Tipp: Wenn Sie Einstellungen ändern, müssen Sie auf Speichern klicken, damit diese wirksam werden.

7. Tipps und Fehlerbehebung

7.1 Optimale Fotosessions

  • Verwenden Sie eine gleichmäßige Beleuchtung ohne starke Schatten
  • Stellen Sie sicher, dass der Hintergrund konstant und möglichst neutral ist
  • Befestigen Sie kleine Objekte sicher auf dem Drehteller
  • Verwenden Sie ein Stativ für die Kamera und halten Sie den Fokus konstant

7.2 Häufige Probleme

Problem Mögliche Lösung
Arduino wird nicht erkannt
  • USB-Kabel und Anschluss überprüfen
  • Korrekten Port in den Einstellungen auswählen
  • Arduino-Treiber neu installieren
Kamera wird nicht erkannt
  • USB-Verbindung prüfen
  • Bei DSLR: Kamera einschalten und in PC-Verbindungsmodus setzen
  • Bei Webcam: Gerätemanager/lsusb prüfen
Drehteller bewegt sich nicht
  • Arduino-Verbindung überprüfen
  • Motoranschlüsse kontrollieren
  • Stromversorgung des Motors prüfen
Fotos sind unscharf
  • Manuellen Fokus verwenden
  • Ausreichende Beleuchtung sicherstellen
  • Längere Belichtungszeit in den Kameraeinstellungen wählen
