ProjectsBlueprint

Routen für die Projektverwaltung

Datei: /app/blueprints/projects/routes.py

Routen

projects_page

@projects_bp.route('/')

Zeigt die Projektverwaltungsseite an

Rückgabewert:

HTML-Template mit der Liste aller Projekte

create_project

@projects_bp.route('/create', methods=['GET', 'POST'])

Erstellt ein neues Projekt

Rückgabewert:

Bei GET: HTML-Template mit dem Projektformular

Bei POST: Weiterleitung zur Projektansicht oder Fehlerseite

view_project

@projects_bp.route('/')

Zeigt ein Projekt an

Parameter:

project_id: ID des Projekts

Rückgabewert:

HTML-Template mit den Projektdetails oder Weiterleitung zur Projektliste

delete_project

@projects_bp.route('/delete/', methods=['POST'])

Löscht ein Projekt

Parameter:

project_id: ID des zu löschenden Projekts

Rückgabewert:

Weiterleitung zur Projektliste oder Fehlerseite

get_project_image

@projects_bp.route('/image//')

Liefert ein Projektbild

Parameter:

project_id: ID des Projekts
image_path: Pfad zum Bild innerhalb des Projekts

Rückgabewert:

Das angeforderte Bild oder eine 404-Fehlerseite
