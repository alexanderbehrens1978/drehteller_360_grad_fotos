Projektmodul (app/blueprints/projects)

Übersicht

Das Projektmodul verwaltet die 360°-Fotoprojekte der Anwendung. Es ermöglicht die Erstellung, Bearbeitung, Anzeige und Löschung von Projekten sowie die Durchführung von Aufnahmesessions und den Export der Projekte in verschiedenen Formaten.

Das Modul ist als Flask-Blueprint implementiert und besteht aus mehreren Komponenten:

  • Routen für die Projektverwaltung (app/blueprints/projects/routes.py)
  • Projektmodell (app/models/project.py)
  • Fotosession-Modell (app/models/photo_session.py)
  • HTML-Templates (templates/project_*.html)
  • JavaScript und CSS für die Benutzeroberfläche

Routen und Funktionen

projects_page()

Route: /projects/

Zeigt die Projektverwaltungsseite an.

Parameter:

Keine

Rückgabewert:

Gerenderte HTML-Seite (projects.html)

create_project()

Route: /projects/create

Erstellt ein neues Projekt oder zeigt das Formular zum Erstellen an.

Parameter:

Keine

Formularfelder (POST):

  • name: Name des Projekts
  • description: Beschreibung des Projekts
  • angle_step: Winkelschritt in Grad

Rückgabewert:

Bei GET: Gerenderte HTML-Seite (project_create.html)

Bei erfolgreichem POST: Weiterleitung zur Projektansicht

Bei Fehler: Gerenderte HTML-Seite mit Fehlermeldung

view_project(project_id)

Route: /projects/<project_id>

Zeigt ein Projekt an.

Parameter:

  • project_id: ID des Projekts

Rückgabewert:

Gerenderte HTML-Seite (project_view.html) oder Weiterleitung zur Projektliste, wenn das Projekt nicht gefunden wird

view_project_360(project_id)

Route: /projects/<project_id>/viewer

Zeigt die 360°-Ansicht eines Projekts an.

Parameter:

  • project_id: ID des Projekts

Rückgabewert:

Gerenderte HTML-Seite (project_viewer.html) mit JavaScript-Daten für den Viewer

edit_project(project_id)

Route: /projects/<project_id>/edit

Bearbeitet ein Projekt oder zeigt das Formular zum Bearbeiten an.

Parameter:

  • project_id: ID des Projekts

Formularfelder (POST):

  • name: Name des Projekts
  • description: Beschreibung des Projekts
  • angle_step: Winkelschritt in Grad

Rückgabewert:

Bei GET: Gerenderte HTML-Seite (project_edit.html)

Bei erfolgreichem POST: Weiterleitung zur Projektansicht

Bei Fehler: Gerenderte HTML-Seite mit Fehlermeldung

capture_session(project_id)

Route: /projects/<project_id>/capture

Startet eine Aufnahmesession für ein Projekt oder zeigt das Formular zum Starten an.

Parameter:

  • project_id: ID des Projekts

Formularfelder (POST):

  • session_name: Name der Session

Rückgabewert:

Bei GET: Gerenderte HTML-Seite (capture.html)

Bei erfolgreichem POST: Weiterleitung zur Projektansicht

Bei Fehler: Gerenderte HTML-Seite mit Fehlermeldung

delete_project(project_id)

Route: /projects/<project_id>/delete

Löscht ein Projekt.

Parameter:

  • project_id: ID des Projekts

Rückgabewert:

Weiterleitung zur Projektliste

get_project_image(project_id, image_path)

Route: /projects/image/<project_id>/<path:image_path>

Liefert ein Projektbild.

Parameter:

  • project_id: ID des Projekts
  • image_path: Pfad zum Bild innerhalb des Projekts

Rückgabewert:

Bilddatei

add_rotation_to_project(project_id)

Route: /projects/<project_id>/add_rotation

Fügt eine Rotation zum Projekt hinzu (dreht und fotografiert).

Parameter:

  • project_id: ID des Projekts

Formularfelder (POST):

  • degrees: Drehwinkel in Grad

Rückgabewert:

JSON-Daten mit Status, Fotopfad und Winkel

export_project(project_id)

Route: /projects/<project_id>/export

Exportiert ein Projekt für externe Verwendung.

Parameter:

  • project_id: ID des Projekts

JSON-Daten (POST):

  • format: Export-Format (html, wordpress, shopify, prestashop)
  • sessionId: ID der zu exportierenden Session (optional)

Rückgabewert:

JSON-Daten mit Status und Download-URL

download_export(filename)

Route: /projects/download/<filename>

Lädt eine exportierte Datei herunter.

Parameter:

  • filename: Name der zu ladenden Datei

Rückgabewert:

Datei zum Herunterladen oder 404-Fehler, wenn die Datei nicht gefunden wird

Beispiel

Beispiel für den Export eines Projekts im HTML-Format:

# 1. Exportanfrage senden
response = requests.post(
    f'http://localhost:5000/projects/{project_id}/export',
    json={
        'format': 'html',
        'sessionId': session_id
    }
)

# 2. Download-URL aus der Antwort extrahieren
data = response.json()
download_url = data['downloadUrl']

# 3. Export herunterladen
export_file = requests.get(f'http://localhost:5000{download_url}')

# 4. Export speichern
with open('360_viewer.zip', 'wb') as f:
    f.write(export_file.content)
