API-Endpunkte

Diese Dokumentation beschreibt die verfügbaren API-Endpunkte der 360° Drehteller Steuerung. Die API ermöglicht die programmatische Interaktion mit der Anwendung und kann für Integrationen und Erweiterungen genutzt werden.

Basis-URL

Alle API-Endpunkte sind unter dem Pfad /api verfügbar. Beispiel: http://localhost:5000/api/projects

Projekte

GET /api/projects

Gibt eine Liste aller verfügbaren Projekte zurück.

Parameter

Keine

Antwort

Feld Typ Beschreibung
projects Array Liste von Projektobjekten

Beispielantwort

{ "projects": [ { "id": "project_12345", "name": "Produktfoto Vase", "description": "Blumenvase für Webshop", "created_at": 1648291200, "angle_step": 15, "sessions": [ { "id": "session_67890", "name": "Session 2025-03-29 14:30", "timestamp": 1648299000, "photo_count": 24 } ] }, { "id": "project_54321", "name": "Schmuckstück", "description": "Silberring mit Edelstein", "created_at": 1648378800, "angle_step": 10, "sessions": [] } ] }

GET /api/projects/{project_id}

Gibt die Details eines bestimmten Projekts zurück.

Parameter

Name Typ Ort Beschreibung Erforderlich
project_id String Pfad ID des Projekts Ja

Antwort

Feld Typ Beschreibung
id String Projekt-ID
name String Projektname
description String Projektbeschreibung
created_at Integer Zeitstempel der Erstellung (Unix-Zeit)
angle_step Integer Winkelschritt in Grad
sessions Array Liste der Fotosessions in diesem Projekt

POST /api/projects

Erstellt ein neues Projekt.

Parameter

Name Typ Ort Beschreibung Erforderlich
name String Body Projektname Ja
description String Body Projektbeschreibung Nein
angle_step Integer Body Winkelschritt in Grad Nein (Standard: 15)

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation
project Object Das neu erstellte Projekt

Beispielanfrage

POST /api/projects Content-Type: application/json { "name": "Neues Produktfoto", "description": "Testprodukt für den Webshop", "angle_step": 10 }

DELETE /api/projects/{project_id}

Löscht ein Projekt.

Parameter

Name Typ Ort Beschreibung Erforderlich
project_id String Pfad ID des zu löschenden Projekts Ja

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation

Hardware-Steuerung

POST /api/rotate

Dreht den Drehteller um einen bestimmten Winkel.

Parameter

Name Typ Ort Beschreibung Erforderlich
degrees Number Body Drehwinkel in Grad (1-360) Ja

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation
position Number Aktuelle Position des Drehtellers in Grad

Beispielanfrage

POST /api/rotate Content-Type: application/json { "degrees": 15 }

POST /api/capture

Nimmt ein Foto mit der konfigurierten Kamera auf.

Parameter

Name Typ Ort Beschreibung Erforderlich
project_id String Body Projekt-ID, in der das Foto gespeichert werden soll Ja
filename String Body Dateiname für das Foto Nein (automatisch generiert, wenn nicht angegeben)

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation
filepath String Pfad zum aufgenommenen Foto

POST /api/session/start

Startet eine automatische Fotosession.

Parameter

Name Typ Ort Beschreibung Erforderlich
project_id String Body Projekt-ID, für die die Session gestartet werden soll Ja

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation
session_id String ID der gestarteten Session

POST /api/session/stop

Stoppt die laufende Fotosession.

Parameter

Keine

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation

Viewer-Generierung

POST /api/viewer/generate

Generiert einen 360°-Viewer für eine Fotosession.

Parameter

Name Typ Ort Beschreibung Erforderlich
project_id String Body Projekt-ID Ja
session_id String Body Session-ID Ja
options Object Body Generierungsoptionen (Bildgröße, Qualität, etc.) Nein

Antwort

Feld Typ Beschreibung
success Boolean Status der Operation
viewer_url String URL zum generierten Viewer

Beispielanfrage

POST /api/viewer/generate Content-Type: application/json { "project_id": "project_12345", "session_id": "session_67890", "options": { "image_size": [800, 600], "quality": 85, "auto_rotate": true } }

Status und Diagnose

GET /api/status

Gibt den Status der Hardware-Komponenten zurück.

Parameter

Keine

Antwort

Feld Typ Beschreibung
arduino Object Status des Arduino (connected, port)
camera Object Status der Kamera (connected, type, device)
turntable Object Status des Drehtellers (ready, current_position)
session Object Status einer laufenden Session (active, project_id, session_id)

Beispielantwort

{ "arduino": { "connected": true, "port": "/dev/ttyUSB0" }, "camera": { "connected": true, "type": "webcam", "device": "/dev/video0" }, "turntable": { "ready": true, "current_position": 45 }, "session": { "active": false, "project_id": null, "session_id": null } }
