Kamera-Controller (app/controllers/camera_controller.py)

Übersicht

Der Kamera-Controller ist verantwortlich für die Steuerung von Kameras zur Aufnahme von Fotos. Er unterstützt sowohl Webcams (über OpenCV) als auch DSLR-Kameras (über gphoto2) und bietet eine einheitliche Schnittstelle für beide Kameratypen.

Der Controller ermöglicht die Konfiguration der Kamera (Auflösung, Gerätepfad) und das Aufnehmen von Fotos mit einem einzigen Methodenaufruf.

Klasse CameraController

Initialisierung

__init__(self, camera_type='webcam', device='/dev/video0', resolution=None)

Initialisiert den Kamera-Controller.

Parameter:

  • camera_type: Kameratyp ('webcam' oder 'gphoto2') (optional, Standard: 'webcam')
  • device: Gerätepfad (optional, Standard: '/dev/video0')
  • resolution: Auflösung als Tupel (Breite, Höhe) oder String 'BreitexHöhe' oder Dictionary mit 'width' und 'height' (optional)

Der Kamera-Controller unterstützt verschiedene Formate für die Auflösung:

  • Tupel: (1920, 1080)
  • String: '1920x1080'
  • Dictionary: {'width': 1920, 'height': 1080}

Wenn keine Auflösung angegeben wird, wird die Standardauflösung 1920x1080 verwendet.

Private Methoden

_check_gphoto2(self)

Prüft, ob gphoto2 installiert ist.

Rückgabewert:

True wenn gphoto2 verfügbar ist, sonst False

_setup_webcam(self)

Initialisiert die Webcam.

Rückgabewert:

True bei Erfolg, False bei Fehler

Diese Methode initialisiert den OpenCV-Videocapture und stellt die konfigurierte Auflösung ein.

_close_webcam(self)

Schließt die Webcam.

Diese Methode gibt die Webcam-Ressourcen frei, indem sie den OpenCV-Videocapture schließt.

Öffentliche Methoden

capture_webcam_photo(self, output_path)

Nimmt ein Foto mit der Webcam auf.

Parameter:

  • output_path: Pfad für das aufgenommene Foto

Rückgabewert:

True bei Erfolg, False bei Fehler

Diese Methode initialisiert die Webcam, nimmt mehrere Frames auf (um der Kamera Zeit zur Anpassung zu geben) und speichert den letzten Frame als Bild.

capture_gphoto2_photo(self, output_path)

Nimmt ein Foto mit einer gphoto2-kompatiblen Kamera auf.

Parameter:

  • output_path: Pfad für das aufgenommene Foto

Rückgabewert:

True bei Erfolg, False bei Fehler

Diese Methode nutzt das gphoto2-Kommandozeilenprogramm, um ein Foto mit einer angeschlossenen DSLR-Kamera aufzunehmen und es direkt als Datei zu speichern.

capture_photo(self, output_path)

Nimmt ein Foto auf (je nach Kameratyp).

Parameter:

  • output_path: Pfad für das aufgenommene Foto

Rückgabewert:

True bei Erfolg, False bei Fehler

Diese Methode ist die Hauptschnittstelle des Controllers und ruft abhängig vom konfigurierten Kameratyp entweder capture_webcam_photo oder capture_gphoto2_photo auf.

cleanup(self)

Ressourcen freigeben, wenn die Kamera nicht mehr benötigt wird.

Diese Methode stellt sicher, dass alle Kameraressourcen ordnungsgemäß freigegeben werden, wenn der Controller nicht mehr benötigt wird.

Beispiele

Beispiel für die Verwendung mit einer Webcam:

# Kamera-Controller für Webcam erstellen
camera = CameraController(
    camera_type='webcam',
    device='/dev/video0',
    resolution=(1280, 720)
)

# Foto aufnehmen
success = camera.capture_photo('output/test_photo.jpg')

if success:
    print('Foto erfolgreich aufgenommen')
else:
    print('Fehler beim Aufnehmen des Fotos')

# Ressourcen freigeben
camera.cleanup()

Beispiel für die Verwendung mit einer DSLR-Kamera:

# Kamera-Controller für DSLR-Kamera erstellen
camera = CameraController(
    camera_type='gphoto2',
    device='auto'  # Automatische Erkennung der Kamera
)

# Foto aufnehmen
success = camera.capture_photo('output/dslr_photo.jpg')

if success:
    print('Foto erfolgreich aufgenommen')
else:
    print('Fehler beim Aufnehmen des Fotos')

# Ressourcen freigeben
camera.cleanup()

Abhängigkeiten

Der Kamera-Controller hat folgende Abhängigkeiten:

Python-Bibliotheken

  • OpenCV (cv2): Für die Steuerung von Webcams 
    pip install opencv-python

Externe Programme

  • gphoto2: Für die Steuerung von DSLR-Kameras 
    sudo apt-get install gphoto2

Fehlerbehandlung

Häufige Probleme und deren Lösung:

Webcam-Probleme

Wenn Probleme mit der Webcam auftreten:

  • Prüfen Sie, ob die Webcam angeschlossen und vom System erkannt wird: 
    ls -l /dev/video*
  • Testen Sie die Webcam mit einem anderen Programm, z.B. VLC oder Cheese
  • Stellen Sie sicher, dass die konfigurierte Auflösung von der Webcam unterstützt wird
  • Prüfen Sie, ob die Rechte für den Gerätezugriff korrekt sind: 
    sudo chmod 666 /dev/video0

gphoto2-Probleme

Wenn Probleme mit der DSLR-Kamera auftreten:

  • Prüfen Sie, ob gphoto2 installiert ist: 
    gphoto2 --version
  • Prüfen Sie, ob die Kamera erkannt wird: 
    gphoto2 --auto-detect
  • Stellen Sie sicher, dass die Kamera im richtigen Modus ist (oft manueller Modus)
  • Prüfen Sie, ob andere Programme auf die Kamera zugreifen
  • Versuchen Sie, die Kamera manuell mit gphoto2 zu steuern: 
    gphoto2 --capture-image-and-download
