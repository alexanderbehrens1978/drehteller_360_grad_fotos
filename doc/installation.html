Installation der 360° Drehteller Steuerung

Diese Anleitung führt Sie durch den Prozess der Installation und Ersteinrichtung der 360° Drehteller Steuerungsanwendung. Folgen Sie den Schritten in der angegebenen Reihenfolge, um eine vollständige und korrekte Installation sicherzustellen.

1. Systemvoraussetzungen

Stellen Sie sicher, dass Ihr System die folgenden Mindestanforderungen erfüllt:

Komponente Anforderung
Betriebssystem Linux (empfohlen: Raspberry Pi OS, Ubuntu) oder Windows
Python Version 3.7 oder höher
Arduino Arduino Nano, Uno oder kompatibel
Kamera USB-Webcam oder gphoto2-kompatible DSLR
Drehteller-Hardware Schrittmotor oder DC-Motor mit Zahnradgetriebe

2. Python-Abhängigkeiten installieren

Die Anwendung benötigt verschiedene Python-Pakete. Diese können mit pip installiert werden:

# Virtuelle Umgebung erstellen (optional, aber empfohlen) python -m venv myenv # Virtuelle Umgebung aktivieren # Unter Linux/macOS: source myenv/bin/activate # Unter Windows: myenv\Scripts\activate # Abhängigkeiten installieren pip install flask gphoto2 pyserial pillow numpy opencv-python

Alternativ können Sie das Setup-Skript verwenden, das alle Abhängigkeiten automatisch installiert:

# Skript ausführbar machen chmod +x setup_and_autostart.sh # Skript ausführen sudo ./setup_and_autostart.sh
Hinweis: Das Setup-Skript benötigt Administratorrechte, um alle erforderlichen Komponenten zu installieren.

3. Arduino-Sketch hochladen

Der Arduino muss mit dem entsprechenden Sketch programmiert werden, um mit der Anwendung kommunizieren zu können:

  1. Stellen Sie sicher, dass die Arduino IDE installiert ist
  2. Öffnen Sie den Sketch aus dem Verzeichnis arduino_drehteller_steuerung
  3. Verbinden Sie den Arduino über USB
  4. Wählen Sie das richtige Board und den seriellen Port in der Arduino IDE
  5. Klicken Sie auf "Hochladen", um den Sketch auf den Arduino zu übertragen

Alternativ können Sie das Upload-Skript verwenden:

# Skript ausführbar machen chmod +x upload_arduino_sketch.sh # Skript mit dem Arduino-Port ausführen ./upload_arduino_sketch.sh /dev/ttyUSB0
Hinweis: Der serielle Port kann je nach System variieren. Häufige Werte sind:
  • Linux: /dev/ttyUSB0 oder /dev/ttyACM0
  • Windows: COM3, COM4, etc.

4. Konfiguration anpassen

Erstellen Sie eine Konfigurationsdatei config.json im Hauptverzeichnis oder passen Sie die vorhandene an:

{ "arduino": { "port": "/dev/ttyUSB0", "baudrate": 9600 }, "camera": { "type": "webcam", "device_path": "/dev/video0", "resolution": [1920, 1080] }, "rotation": { "default_degrees": 15 }, "paths": { "projects": "projects", "photos": "photos" } }

Passen Sie die Pfade und Einstellungen entsprechend Ihrem System an.

5. Anwendung starten

Starten Sie die Anwendung mit dem folgenden Befehl:

# Normale Ausführung python run.py # Mit bestimmter Host-Adresse und Port python run.py --host 0.0.0.0 --port 5000 # Im Produktionsmodus python run.py --env production

Alternativ können Sie das Start-Skript verwenden:

# Skript ausführbar machen chmod +x drehteller.sh # Skript starten ./drehteller.sh

6. Autostart einrichten (optional)

Wenn die Anwendung automatisch beim Systemstart gestartet werden soll, können Sie dies mit dem Setup-Script konfigurieren:

# Autostart-Option aktivieren sudo ./setup_and_autostart.sh --autostart

Dies erstellt einen Systemd-Service unter Linux, der die Anwendung automatisch startet.

7. Hardware anschließen

Verbinden Sie die Hardware mit dem System:

  1. Arduino über USB anschließen
  2. Kamera (Webcam oder DSLR) über USB anschließen
  3. Überprüfen Sie die Verbindungen zum Drehteller und den Motoranschluss
Wichtig: Stellen Sie sicher, dass die Stromversorgung des Motors ausreichend ist. Bei Verwendung eines externen Netzteils für den Motor ist eine gemeinsame Masse mit dem Arduino erforderlich.

8. Zugriff auf die Weboberfläche

Öffnen Sie einen Webbrowser und navigieren Sie zur Anwendung:

  • Lokal: http://localhost:5000
  • Von einem anderen Gerät im Netzwerk: http://[IP-ADRESSE]:5000

Sie sollten nun die Startseite der 360° Drehteller Steuerung sehen.

9. Fehlersuche bei Installationsproblemen

Wenn bei der Installation Probleme auftreten, können folgende Schritte helfen:

  • Überprüfen Sie die Logdateien im Verzeichnis logs
  • Führen Sie den Diagnose-Modus aus: python diagnose_modules.py
  • Stellen Sie sicher, dass alle erforderlichen Berechtigungen vorhanden sind (besonders für USB-Geräte)
  • Unter Linux kann es erforderlich sein, den Benutzer zu den Gruppen dialout und video hinzuzufügen:
    sudo usermod -a -G dialout,video $USER
