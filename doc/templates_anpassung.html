Templates und Static Files

Diese Dokumentation erklärt die Struktur, Verwendung und Anpassung der Templates und statischen Dateien im 360° Drehteller Steuerungssystem.

1. Projektstruktur

Die Webanwendung verwendet das Flask-Framework und folgt dessen typischer Struktur:

app/
├── static/ # Statische Dateien (CSS, JS, Bilder)
│ ├── css/
│ ├── js/
│ └── images/
├── templates/ # HTML-Templates
│ ├── base.html # Basis-Template mit Header und Footer
│ ├── index.html # Startseite
│ ├── projects/ # Projekt-bezogene Templates
│ ├── settings/ # Einstellungs-Templates
│ └── viewer/ # 360° Viewer Templates
└── ... andere Dateien und Ordner

2. Wie Templates funktionieren

Das System verwendet Jinja2 als Template-Engine, die in Flask integriert ist. Templates ermöglichen die Trennung von Logik und Darstellung.

2.1 Template-Vererbung

Alle Templates erben von base.html, was eine einheitliche Struktur mit Header und Footer gewährleistet:

<!-- base.html --> <!DOCTYPE html> <html> <head> <title>{% block title %}360° Drehteller{% endblock %}</title> <link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}"> {% block head %}{% endblock %} </head> <body> <header> <!-- Navigation --> </header> <main> {% block content %}{% endblock %} </main> <footer> <p>© 2025 360° Drehteller Steuerung</p> </footer> <script src="{{ url_for('static', filename='js/common.js') }}"></script> {% block scripts %}{% endblock %} </body> </html>

Andere Templates erweitern dieses Basis-Template:

<!-- index.html --> {% extends "base.html" %} {% block title %}Startseite - 360° Drehteller{% endblock %} {% block content %} <h1>Willkommen zur 360° Drehteller Steuerung</h1> <!-- Weitere Inhalte --> {% endblock %}

3. Anpassung von Templates

3.1 Ändern bestehender Templates

Um bestehende Templates zu ändern, bearbeiten Sie einfach die entsprechende Datei im templates-Verzeichnis:

  1. Navigieren Sie zum app/templates/-Verzeichnis
  2. Öffnen Sie die gewünschte Template-Datei mit einem Texteditor
  3. Nehmen Sie Ihre Änderungen vor
  4. Speichern Sie die Datei
  5. Starten Sie die Flask-Anwendung neu, falls sie bereits läuft
Tipp: Flask hat einen Debug-Modus, der automatisch Template-Änderungen erkennt. Wenn die Anwendung mit flask run --debug gestartet wird, sind Änderungen sofort sichtbar, ohne Neustart.

3.2 Ändern des Footers

Der Footer ist im base.html-Template definiert und wird auf allen Seiten angezeigt:

  1. Öffnen Sie app/templates/base.html
  2. Suchen Sie den Footer-Bereich:
<footer> <p>© 2025 360° Drehteller Steuerung</p> </footer>

Bearbeiten Sie diesen Abschnitt nach Ihren Wünschen. Beispiel:

<footer> <p>© 2025 Ihre Firma - 360° Drehteller Steuerung</p> <p>Kontakt: info@example.com | Tel: +49 123 456789</p> </footer>

3.3 Erstellen neuer Templates

Um ein neues Template zu erstellen:

  1. Erstellen Sie eine neue .html-Datei im geeigneten Unterverzeichnis von templates/
  2. Beginnen Sie mit der Vererbung vom Base-Template: {% extends "base.html" %}
  3. Definieren Sie die benötigten Blöcke (title, content, scripts, etc.)
  4. Fügen Sie Ihren HTML-Inhalt hinzu

Beispiel für ein neues Template:

{% extends "base.html" %} {% block title %}Meine neue Seite{% endblock %} {% block content %} <h1>Meine neue Funktionalität</h1> <p>Hier kommt der neue Inhalt.</p> {% if user_data %} <p>Hallo, {{ user_data.name }}!</p> {% endif %} {% endblock %}

4. Statische Dateien anpassen

Statische Dateien (CSS, JavaScript, Bilder) befinden sich im static-Verzeichnis.

4.1 CSS-Anpassungen

Um das Erscheinungsbild der Anwendung zu ändern:

  1. Bearbeiten Sie app/static/css/style.css
  2. Fügen Sie neue CSS-Regeln hinzu oder ändern Sie bestehende
Tipp: Verwenden Sie den Browser-Inspektor (F12), um zu identifizieren, welche CSS-Regeln Sie ändern müssen.

4.2 JavaScript-Anpassungen

JavaScript-Dateien steuern die interaktiven Elemente der Oberfläche:

  1. Bearbeiten Sie die relevante JS-Datei in app/static/js/
  2. Testen Sie Ihre Änderungen im Browser

Hauptskripte:

  • common.js - Auf allen Seiten verwendete Funktionen
  • projects.js - Projektverwaltungsfunktionen
  • settings.js - Einstellungsbezogene Funktionen
  • viewer.js - 360° Viewer Funktionalität

5. Daten in Templates einfügen

5.1 Variablen an Templates übergeben

In den Flask-Routen werden Daten an Templates übergeben:

# In einer Route-Funktion (app/blueprints/main.py oder ähnlich) @main.route('/') def index(): user_name = "Max Mustermann" projects_count = 5 return render_template('index.html', user_name=user_name, projects_count=projects_count)

Im Template werden diese Variablen mit doppelten geschweiften Klammern angezeigt:

<!-- In templates/index.html --> <p>Hallo, {{ user_name }}!</p> <p>Sie haben {{ projects_count }} Projekte.</p>

5.2 Neue Daten hinzufügen

Um neue Daten in Templates anzuzeigen:

  1. Identifizieren Sie die Route, die das Template rendert (z.B. in app/blueprints/main.py)
  2. Fügen Sie die neue Variable zur render_template()-Funktion hinzu
  3. Aktualisieren Sie das Template, um die neue Variable anzuzeigen

Beispiel:

# Hinzufügen einer neuen Variable (app/blueprints/main.py) @main.route('/') def index(): # Bestehender Code user_name = "Max Mustermann" projects_count = 5 # Neue Variable hinzufügen last_login = "2025-03-30 10:15" return render_template('index.html', user_name=user_name, projects_count=projects_count, last_login=last_login) # Neue Variable übergeben

Und im Template:

<!-- In templates/index.html --> <p>Hallo, {{ user_name }}!</p> <p>Sie haben {{ projects_count }} Projekte.</p> <p>Letzte Anmeldung: {{ last_login }}</p> <!-- Neue Variable anzeigen -->

5.3 Bereitstellen von globalen Daten für alle Templates

Für Daten, die in jedem Template verfügbar sein sollen (z.B. Versionsinfo oder Systemstatus):

# In app/__init__.py oder einer anderen Initialisierungsdatei @app.context_processor def inject_global_vars(): """Fügt allen Templates globale Variablen hinzu.""" return { 'app_version': '1.2.0', 'company_name': 'Ihre Firma GmbH', 'support_email': 'support@example.com' }

Diese Variablen sind dann in jedem Template verfügbar:

<!-- In jedem Template nutzbar --> <footer> <p>© 2025 {{ company_name }} - 360° Drehteller Steuerung v{{ app_version }}</p> <p>Support: {{ support_email }}</p> </footer>

6. Kontrollstrukturen in Templates

Jinja2 bietet verschiedene Kontrollstrukturen für Templates:

6.1 Bedingungen (if/else)

{% if user_is_admin %} <div class="admin-panel"> <h3>Administration</h3> <!-- Admin-Elemente --> </div> {% else %} <p>Sie haben keinen Zugriff auf die Verwaltungsfunktionen.</p> {% endif %}

6.2 Schleifen (for)

<ul class="project-list"> {% for project in projects %} <li> <h4>{{ project.name }}</h4> <p>{{ project.description }}</p> </li> {% else %} <li>Keine Projekte vorhanden.</li> {% endfor %} </ul>

6.3 Einbinden anderer Templates

{# Einbinden eines allgemeinen Navigationsmenüs #} {% include 'components/navigation.html' %} {# Einbinden mit Variablen #} {% include 'components/project_card.html' with context %}

7. Werte im System abfragen und setzen

7.1 Konfigurationswerte

Die Anwendung verwendet eine zentrale Konfigurationsverwaltung:

# Konfigurationswerte abfragen from app.utils.config_manager import ConfigManager config = ConfigManager() arduino_port = config.get('arduino', 'port') camera_type = config.get('camera', 'type') # Konfigurationswerte setzen config.set('arduino', 'port', 'COM3') config.set('camera', 'resolution', '1920x1080') config.save() # Speichert die Änderungen in der Konfigurationsdatei

7.2 Datenbankinformationen

Projekte und andere Daten werden in einer Datenbank gespeichert:

# Projekt abfragen from app.models.project import Project project = Project.get_by_id('project_12345') project_name = project.name photos_count = project.get_photos_count() # Projekt aktualisieren project.name = "Neuer Projektname" project.description = "Neue Beschreibung" project.save()

7.3 Hardware-Status

Der aktuelle Hardware-Status kann abgefragt werden:

# Arduino-Status prüfen from app.controllers.arduino_controller import ArduinoController arduino = ArduinoController() connected = arduino.is_connected() position = arduino.get_current_position() # Kamera-Status prüfen from app.controllers.camera_controller import CameraController camera = CameraController() camera_ready = camera.is_ready() available_cameras = camera.get_available_cameras()

8. Praktische Beispiele

Beispiel 1: Footer mit dynamischen Informationen

Anpassung des Footers mit dynamischen Informationen:

  1. Globale Variablen definieren:
# In app/__init__.py @app.context_processor def inject_footer_info(): # Hier könnten Werte aus einer Datenbank oder Konfiguration kommen return { 'company_name': 'Ihre Firma GmbH', 'current_year': datetime.now().year, 'version': '1.2.3', 'contact_email': 'info@example.com' }
  1. Footer in base.html anpassen:
<footer> <div class="footer-content"> <div class="copyright"> <p>© {{ current_year }} {{ company_name }} - 360° Drehteller Steuerung v{{ version }}</p> </div> <div class="contact"> <p>Kontakt: {{ contact_email }}</p> </div> <div class="system-status"> {% if arduino_connected %} <span class="status-indicator connected">Arduino verbunden</span> {% else %} <span class="status-indicator disconnected">Arduino nicht verbunden</span> {% endif %} {% if camera_ready %} <span class="status-indicator connected">Kamera bereit</span> {% else %} <span class="status-indicator disconnected">Kamera nicht bereit</span> {% endif %} </div> </div> </footer>

Beispiel 2: Neues Template mit benutzerdefinierten Daten

Erstellen einer benutzerdefinierten Statistikseite:

  1. Neue Route definieren:
# In app/blueprints/main.py @main.route('/statistics') def statistics(): # Daten sammeln stats = { 'total_projects': Project.count_all(), 'total_photos': PhotoSession.count_all_photos(), 'most_active_project': Project.get_most_active(), 'system_uptime': get_system_uptime(), 'disk_usage': get_disk_usage(), } return render_template('statistics.html', stats=stats)
  1. Neues Template erstellen (templates/statistics.html):
{% extends "base.html" %} {% block title %}Systemstatistiken{% endblock %} {% block content %} <div class="statistics-container"> <h1>Systemstatistiken</h1> <div class="stat-card"> <h3>Projekte</h3> <p class="stat-number">{{ stats.total_projects }}</p> </div> <div class="stat-card"> <h3>Fotos</h3> <p class="stat-number">{{ stats.total_photos }}</p> </div> {% if stats.most_active_project %} <div class="stat-card"> <h3>Aktivstes Projekt</h3> <p>{{ stats.most_active_project.name }}</p> <p>{{ stats.most_active_project.photos_count }} Fotos</p> </div> {% endif %} <div class="stat-card"> <h3>Systemlaufzeit</h3> <p>{{ stats.system_uptime }}</p> </div> <div class="stat-card"> <h3>Speichernutzung</h3> <p>{{ stats.disk_usage.used }} von {{ stats.disk_usage.total }} ({{ stats.disk_usage.percent }}%)</p> <div class="progress-bar"> <div class="progress" style="width: {{ stats.disk_usage.percent }}%"></div> </div> </div> </div> {% endblock %}
  1. Link zur Navigation hinzufügen (in base.html):
<nav> <ul> <li><a href="{{ url_for('main.index') }}">Startseite</a></li> <li><a href="{{ url_for('projects.list') }}">Projekte</a></li> <li><a href="{{ url_for('settings.index') }}">Einstellungen</a></li> <li><a href="{{ url_for('viewer.index') }}">360° Viewer</a></li> <li><a href="{{ url_for('main.statistics') }}">Statistiken</a></li> </ul> </nav>
