Arduino-Controller (app/controllers/arduino_controller.py)

Übersicht

Der Arduino-Controller ist verantwortlich für die Kommunikation mit dem Arduino-Mikrocontroller, der den Drehteller steuert. Er bietet eine einfache Schnittstelle zum Ein- und Ausschalten des Motors sowie zur Steuerung der Rotationsdauer.

Der Controller nutzt die serielle Kommunikation, um mit dem Arduino zu kommunizieren. Er sendet einfache Befehle, um das Relais zu steuern, das den Motor ein- und ausschaltet.

Klasse ArduinoController

Initialisierung

__init__(self, port=None, baudrate=9600)

Initialisiert die Arduino-Verbindung.

Parameter:

  • port: Serieller Port (optional)
  • baudrate: Baudrate (optional, Standard: 9600)

Der Controller versucht, eine Verbindung zum Arduino herzustellen, wenn ein Port angegeben wird. Andernfalls muss die Verbindung später mit connect() hergestellt werden.

Methoden

connect(self)

Stellt eine Verbindung zum Arduino her.

Rückgabewert:

True bei Erfolg, False bei Fehler

disconnect(self)

Trennt die Verbindung zum Arduino.

Rückgabewert:

True bei Erfolg, False bei Fehler

is_connected(self)

Prüft, ob die Verbindung zum Arduino hergestellt ist.

Rückgabewert:

True wenn verbunden, sonst False

send_command(self, command)

Sendet einen Befehl an den Arduino.

Parameter:

  • command: Zu sendender Befehl

Rückgabewert:

True bei Erfolg, False bei Fehler

Die Methode wartet auf eine Antwort vom Arduino und gibt True zurück, wenn die Antwort "OK" ist. Bei Fehlern oder Timeout gibt sie False zurück.

turn_motor_on(self)

Schaltet den Motor ein (Relais schließen).

Rückgabewert:

True bei Erfolg, False bei Fehler

turn_motor_off(self)

Schaltet den Motor aus (Relais öffnen).

Rückgabewert:

True bei Erfolg, False bei Fehler

rotate_for_duration(self, duration_ms)

Dreht den Motor für eine bestimmte Zeit.

Parameter:

  • duration_ms: Dauer in Millisekunden

Rückgabewert:

True bei Erfolg, False bei Fehler

Die Methode schaltet den Motor ein, wartet für die angegebene Dauer und schaltet ihn dann wieder aus. Sie gibt True zurück, wenn der gesamte Vorgang erfolgreich war.

Beispiel

Beispiel für die Verwendung des Arduino-Controllers:

# Arduino-Controller erstellen und verbinden
arduino = ArduinoController(port='/dev/ttyACM0', baudrate=9600)

# Prüfen, ob die Verbindung erfolgreich war
if arduino.is_connected():
    # Motor für 5 Sekunden (5000 ms) einschalten
    arduino.rotate_for_duration(5000)
    
    # Verbindung trennen
    arduino.disconnect()
else:
    print("Konnte keine Verbindung zum Arduino herstellen")

Arduino-Sketch

Der Arduino-Controller setzt voraus, dass der Arduino mit dem folgenden Sketch programmiert ist: 

/*
 * Drehteller-Steuerung
 * 
 * Ein einfacher Sketch, um ein Relais zu steuern,
 * das den Motor des Drehtellers ein- und ausschaltet.
 */

const int relayPin = 8;  // Pin des Relais

void setup() {
  // Serielle Verbindung initialisieren
  Serial.begin(9600);
  
  // Relais-Pin als Ausgang konfigurieren
  pinMode(relayPin, OUTPUT);
  
  // Relais ausschalten (LOW oder HIGH, je nach Relais-Typ)
  digitalWrite(relayPin, LOW);
  
  Serial.println("Drehteller-Steuerung bereit");
}

void loop() {
  // Auf Befehle von der seriellen Schnittstelle warten
  if (Serial.available() > 0) {
    char command = Serial.read();
    
    switch (command) {
      case '1':
        // Relais einschalten
        digitalWrite(relayPin, HIGH);
        Serial.println("OK");
        break;
        
      case '0':
        // Relais ausschalten
        digitalWrite(relayPin, LOW);
        Serial.println("OK");
        break;
        
      default:
        // Unbekannter Befehl
        Serial.println("FEHLER: Unbekannter Befehl");
        break;
    }
  }
}

Fehlerbehandlung

Häufige Probleme und deren Lösung:

Verbindungsprobleme

Wenn keine Verbindung zum Arduino hergestellt werden kann, prüfen Sie folgendes:

  • Ist der Arduino angeschlossen und wird er vom System erkannt? ls -l /dev/ttyACM* oder ls -l /dev/ttyUSB*
  • Sind die Rechte für den seriellen Port korrekt gesetzt? sudo chmod 666 /dev/ttyACM0
  • Ist der richtige Port in den Einstellungen konfiguriert?
  • Stimmt die Baudrate mit der im Arduino-Sketch überein?

Kommunikationsprobleme

Wenn die Verbindung besteht, aber Befehle nicht ausgeführt werden:

  • Prüfen Sie, ob der Arduino-Sketch korrekt hochgeladen wurde und die Befehle '0' und '1' versteht.
  • Überprüfen Sie das Relais und dessen Verbindung mit dem Arduino.
  • Prüfen Sie, ob der Arduino genügend Strom erhält.
  • Überprüfen Sie, ob das Relais für die Last (Motor) geeignet ist.
