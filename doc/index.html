Einstellungen-Modul

Das Einstellungen-Modul ermöglicht die Konfiguration der Hardware-Komponenten der 360° Drehteller Steuerung.

Dateien

  • app/blueprints/settings/routes.py - Enthält die API-Endpunkte
  • templates/settings.html - Die HTML-Vorlage für die Einstellungsseite
  • static/css/settings.css - CSS-Stile spezifisch für die Einstellungsseite
  • static/js/settings.js - JavaScript-Funktionen für die Einstellungsseite

Funktionen

settings()

Funktion in app/blueprints/settings/routes.py

Zeigt die Einstellungsseite an.

Route: GET /settings/

get_config()

Funktion in app/blueprints/settings/routes.py

Gibt die aktuelle Konfiguration als JSON zurück.

Route: GET /settings/get_config

Rückgabe: JSON-Objekt mit der aktuellen Konfiguration

save_config()

Funktion in app/blueprints/settings/routes.py

Speichert die übergebene Konfiguration.

Route: POST /settings/save_config

Erwartet: JSON-Objekt mit der zu speichernden Konfiguration

Rückgabe: JSON-Objekt mit Status der Operation

Konfigurationsmanager

Der Konfigurationsmanager ist zuständig für das Laden, Speichern und Verwalten der Anwendungskonfiguration.

Dateien

  • app/utils/config_manager.py - Enthält die ConfigManager-Klasse

Funktionen

ConfigManager.__init__()

Initialisiert die Konfigurationsverwaltung.

Parameter: config_path (optional) - Pfad zur Konfigurationsdatei

ConfigManager.load_config()

Lädt die Konfiguration aus der Datei oder erstellt die Standardkonfiguration.

Rückgabe: Dictionary mit der Konfiguration

ConfigManager.save_config()

Speichert die Konfiguration in der Datei.

Parameter: new_config (optional) - Neue Konfiguration als Dictionary

Rückgabe: True bei Erfolg, False bei Fehler

ConfigManager.get()

Gibt einen Konfigurationswert zurück.

Parameter:

  • key - Durch Punkte getrennter Schlüssel (z.B. 'camera.device_path')
  • default (optional) - Standardwert, falls Schlüssel nicht gefunden

Rückgabe: Konfigurationswert oder Standardwert

360° Viewer-Module

Die Anwendung unterstützt verschiedene 360° Viewer-Bibliotheken zur Darstellung der aufgenommenen Fotos. Jede Bibliothek hat ihre eigenen Stärken und kann je nach Anforderung gewählt werden.

Integration der Viewer

Für die Integration der verschiedenen Viewer sind folgende Dateien relevant:

  • templates/viewer_pannellum.html - Template für den Pannellum-Viewer
  • templates/viewer_photo_sphere.html - Template für den Photo Sphere Viewer
  • templates/viewer_marzipano.html - Template für den Marzipano-Viewer
  • static/js/viewer_pannellum.js - JavaScript-Funktionen für den Pannellum-Viewer
  • static/js/viewer_photo_sphere.js - JavaScript-Funktionen für den Photo Sphere Viewer
  • static/js/viewer_marzipano.js - JavaScript-Funktionen für den Marzipano-Viewer

Pannellum Viewer

Pannellum ist eine leichte und kostenlose Open-Source-Bibliothek, die vollständig auf HTML5, CSS3 und WebGL basiert. Sie ermöglicht die Darstellung von 360-Grad-Bildern ohne zusätzliche Plugins.

Integration


<!-- HTML-Einbindung -->
<div id="panorama"></div>

<!-- JavaScript-Einbindung -->
<script src="https://cdn.pannellum.org/2.5/pannellum.js"></script>
<script>
    pannellum.viewer('panorama', {
        "type": "equirectangular",
        "panorama": "pfad/zu/ihrem/360-grad-bild.jpg",
        "autoLoad": true,
        "showZoomCtrl": true,
        "showFullscreenCtrl": true
    });
</script>

Konfigurationsoptionen

  • type: Art des Panoramas, meist "equirectangular"
  • panorama: Pfad zum Panoramabild
  • autoLoad: Automatisches Laden des Panoramas
  • showZoomCtrl: Anzeigen der Zoom-Steuerelemente
  • showFullscreenCtrl: Anzeigen der Vollbild-Steuerelemente

Photo Sphere Viewer

Photo Sphere Viewer unterstützt sowohl equirektangulare Panoramen als auch Cubemaps und bietet zahlreiche Anpassungsmöglichkeiten sowie Plugins für erweiterte Funktionen.

Integration


<!-- HTML-Einbindung -->
<div id="viewer" style="width: 100%; height: 500px;"></div>

<!-- JavaScript-Einbindung -->
<script src="https://cdn.jsdelivr.net/npm/three/build/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/photo-sphere-viewer@4/dist/photo-sphere-viewer.min.js"></script>
<script>
    const viewer = new PhotoSphereViewer.Viewer({
        container: document.getElementById('viewer'),
        panorama: 'pfad/zu/ihrem/360-grad-bild.jpg',
        navbar: ['autorotate', 'zoom', 'fullscreen']
    });
</script>

Konfigurationsoptionen

  • container: HTML-Element, in dem der Viewer angezeigt wird
  • panorama: Pfad zum Panoramabild
  • navbar: Steuerelemente in der Navigationsleiste

Marzipano Viewer

Marzipano ist ein 360-Grad-Viewer, der für moderne Webanwendungen entwickelt wurde. Er unterstützt alle gängigen Desktop-Browser und mobilen Geräte und nutzt Standard-Webtechnologien.

Integration


<!-- HTML-Einbindung -->
<div id="pano" style="width: 100%; height: 500px;"></div>

<!-- JavaScript-Einbindung -->
<script src="https://cdn.jsdelivr.net/npm/marzipano@0.10.2/dist/marzipano.min.js"></script>
<script>
    // Viewer erstellen
    var viewer = new Marzipano.Viewer(document.getElementById('pano'));
    
    // Quelle und Geometrie erstellen
    var source = Marzipano.ImageUrlSource.fromUrl('pfad/zu/ihrem/360-grad-bild.jpg');
    var geometry = new Marzipano.EquirectGeometry([{ width: 4000 }]);
    
    // Ansicht erstellen
    var limiter = Marzipano.RectilinearView.limit.traditional(1024, 100*Math.PI/180);
    var view = new Marzipano.RectilinearView(null, limiter);
    
    // Szene erstellen und anzeigen
    var scene = viewer.createScene({
        source: source,
        geometry: geometry,
        view: view,
        pinFirstLevel: true
    });
    scene.switchTo();
</script>

Konfigurationsoptionen

  • Marzipano.Viewer: Erstellt den Viewer im angegebenen HTML-Element
  • Marzipano.ImageUrlSource.fromUrl: Definiert die Bildquelle
  • Marzipano.EquirectGeometry: Definiert die Geometrie des Panoramas
  • Marzipano.RectilinearView: Definiert die Ansicht
