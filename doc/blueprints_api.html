API-Modul (app/blueprints/api)

Übersicht

Das API-Modul stellt HTTP-Endpunkte bereit, die von der Weboberfläche oder anderen Anwendungen genutzt werden können, um mit der Drehteller-Steuerung zu interagieren. Es ermöglicht den Zugriff auf Projekte, Geräte und Einstellungen sowie die Steuerung des Drehtellers und der Kamera.

Das Modul ist als Flask-Blueprint implementiert und liefert Daten im JSON-Format zurück.

Endpunkte

Projekte

Projekt abrufen

GET /api/project/<project_id>

Liefert Metadaten zu einem bestimmten Projekt.

Parameter:
  • project_id: ID des Projekts
Antwort:
{
    "name": "Beispielprojekt",
    "created": 1741791500,
    "image_count": 24,
    "images": ["image_001.jpg", "image_002.jpg", ...],
    "user_metadata": { ... }
}

Alle Projekte abrufen

GET /api/projects

Liefert eine Liste aller verfügbaren Projekte.

Antwort:
[
    {
        "id": "project_123456",
        "name": "Beispielprojekt 1",
        "created": 1741791500,
        "image_count": 24
    },
    {
        "id": "project_654321",
        "name": "Beispielprojekt 2",
        "created": 1741790000,
        "image_count": 36
    }
]

Projekt löschen

DELETE /api/project/<project_id>

Löscht ein Projekt und alle zugehörigen Dateien.

Parameter:
  • project_id: ID des Projekts
Antwort:
{
    "status": "success"
}

Geräte

Verfügbare Geräte abrufen

GET /api/devices

Liefert eine Liste aller erkannten Geräte (Kameras, Arduino).

Antwort:
{
    "cameras": {
        "webcams": ["/dev/video0", "/dev/video1"],
        "gphoto2": ["Canon EOS 700D"]
    },
    "arduinos": [
        {
            "port": "/dev/ttyACM0",
            "description": "Arduino Uno"
        }
    ]
}

360°-Viewer

360°-Viewer generieren

POST /api/generate_360

Generiert einen 360°-Viewer aus den aufgenommenen Bildern.

Anfrage (JSON):
{
    "name": "Mein Projekt",
    "description": "Beschreibung des Projekts"
}
Antwort:
{
    "status": "success",
    "url": "/viewer?project=project_123456"
}

Kamera

Kamera-Fähigkeiten abrufen

GET /api/camera_capabilities

Gibt die Fähigkeiten der aktuell konfigurierten Kamera zurück.

Antwort:
{
    "status": "success",
    "capabilities": {
        "supported_resolutions": [
            [640, 480],
            [1280, 720],
            [1920, 1080]
        ],
        "max_width": 1920,
        "max_height": 1080
    }
}

Status

Arduino-Status abrufen

GET /api/status/arduino

Gibt den aktuellen Status des Arduino zurück.

Antwort:
{
    "connected": true,
    "port": "/dev/ttyACM0",
    "baudrate": 9600
}

Kamera-Status abrufen

GET /api/status/camera

Gibt den aktuellen Status der Kamera zurück.

Antwort:
{
    "available": true,
    "type": "webcam",
    "device": "/dev/video0",
    "resolution": {
        "width": 1280,
        "height": 720
    }
}

Fehlerbehandlung

Die API gibt bei Fehlern einen entsprechenden HTTP-Statuscode und eine JSON-Antwort mit einer Fehlermeldung zurück.

Fehlerantwort

{
    "error": "Fehlermeldung"
}

Mögliche HTTP-Statuscodes:

  • 400 Bad Request: Ungültige Anfrageparameter
  • 404 Not Found: Ressource nicht gefunden
  • 500 Internal Server Error: Interner Serverfehler

Beispiel

Hier ist ein Beispiel für die Verwendung der API mit JavaScript: 

// Alle Projekte abrufen
fetch('/api/projects')
    .then(response => response.json())
    .then(projects => {
        console.log('Verfügbare Projekte:', projects);
    })
    .catch(error => {
        console.error('Fehler beim Abrufen der Projekte:', error);
    });

// 360°-Viewer generieren
fetch('/api/generate_360', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        name: 'Mein neues Projekt',
        description: 'Ein Testprojekt'
    })
})
    .then(response => response.json())
    .then(data => {
        if (data.status === 'success') {
            window.location.href = data.url;
        } else {
            console.error('Fehler:', data.error);
        }
    })
    .catch(error => {
        console.error('Fehler beim Generieren des Viewers:', error);
    });

Sicherheit

Die API ist derzeit nicht authentifiziert und sollte nur in vertrauenswürdigen Netzwerken eingesetzt werden. Für den Einsatz im Internet sollten zusätzliche Sicherheitsmaßnahmen implementiert werden:

  • Authentifizierung (z.B. über Token oder Benutzername/Passwort)
  • Rate Limiting
  • HTTPS-Verschlüsselung
  • CSRF-Schutz
