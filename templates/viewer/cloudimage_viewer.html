Frühere Exporte anzeigen

Anleitung zur Einbindung

Nach dem Export erhalten Sie eine ZIP-Datei mit dem 360° Viewer. Um den Viewer in Ihre Webseite einzubinden:

  1. Entpacken Sie die ZIP-Datei in einen Ordner auf Ihrem Webserver
  2. Binden Sie die index.html direkt ein oder kopieren Sie den Code in Ihre Webseite
  3. Alternativ können Sie den Viewer über einen iFrame einbinden:
<iframe src="pfad/zum/viewer/index.html" width="100%" height="500" frameborder="0"></iframe>
